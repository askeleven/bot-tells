Not an AI detector

bot-tells cannot tell who wrote a message, and does not try. People write every one of these phrases too. It finds the things a reader would hold against the message, whoever wrote it.

A leak, such as a [First Name] nobody filled or a "Here's a draft:" left at the top, fails the message outright. Tells only add to the score.

For agents and pipelines

The same checks as a CLI, a library and an MCP server, so an agent can check its own writing before it sends anything.

npx @askeleven/bot-tells draft.txt
